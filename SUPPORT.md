# Support

## Open-source projects

- **Bugs and feature requests:** open an issue in the relevant repository, using the issue templates.
- **Questions about using a project:** check the repository's README first, then open an issue if you're still stuck.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Don't open a public issue.
