# .github

This repository holds the public organization profile and shared defaults for [SoftPulze](https://softpulze.com).

## What's here

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The profile shown at [github.com/thesoftpulze](https://github.com/thesoftpulze). |

## Community health files

Files added to the root of this repository, or to a `.github/` folder in it, become the defaults for every public SoftPulze repository that doesn't have its own copy. Examples are `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, and issue and pull request templates. See [GitHub's documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the full list.

## Updating the profile

Edit `profile/README.md` and push to `main`. The changes appear on the organization page right away. The logo is loaded from `softpulze.com/brand/`, so update it on the website rather than here.
